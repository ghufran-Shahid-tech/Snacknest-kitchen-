# 🍽️ Snacknest Kitchen Billing System

A modern, responsive, and easy-to-use **Restaurant Point of Sale (POS) & Billing System** built for **Snacknest Kitchen**. This web-based application helps restaurants manage orders, generate receipts, calculate totals instantly, and streamline the billing process with a clean and intuitive interface.

🔗 **Website:**

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Ghufran-Shahid-Tech/Snacknest-Billing.git
```

Go to the project folder

```bash

```

Run the project

```text
Open index.html
```

Or launch with **Live Server** in Visual Studio Code.

# 📸 Application Modules

### 🍽️ Menu Management
Browse food categories and add items to the bill.

### 👤 Customer Details
Store customer name, phone number, address, order type, and payment method.

### 🧾 Billing
Generate accurate bills with automatic calculations.

### 🎟️ Token System
Assign and manage order token numbers.

### 🖨️ Receipt
Generate a clean, printable restaurant receipt.

### 🖼️ Food Gallery
Display high-quality food images for a better user experience.

## ❤️ About Snacknest Kitchen Billing

**Snacknest Kitchen Billing System** is a lightweight, modern POS solution designed to simplify restaurant order management. It offers a clean interface for managing menu items, customer details, billing, and receipt generation, making daily restaurant operations faster and more efficient.
